Beauty Parlour Web App 🌸

A premium, modern, and elegant responsive website designed for a luxury beauty parlour or salon. This project is built from scratch using clean, beginner-friendly web technologies without relying on heavy frameworks.

🚀 Technologies Used

HTML5 (Semantic structure)

CSS3 (Custom styling, Flexbox, CSS Grid, CSS Variables)

Vanilla JavaScript (DOM manipulation, Intersection Observer API)

No Frameworks (No React, No Bootstrap, No jQuery)

✨ Key Features

Fully Responsive Design: Adapts beautifully to mobile phones, tablets, and desktop screens.

True Parallax Scrolling: 3D depth effect where background images move slower than the foreground.

Scrollytelling: Interactive vertical scrolling experience where sticky images change as you read the text.

Scroll-Triggered Reveals: Smooth fade-in and slide-up animations powered by the IntersectionObserver API for excellent performance.

Lightbox Gallery: Click on any gallery image to view it in a full-screen, zoom-in overlay.

Premium Mobile Menu: A custom hamburger menu that animatedly transforms into an 'X' and smoothly slides in from the side.

Accessible & Respects Preferences: Includes prefers-reduced-motion queries to disable animations for users who prefer less movement.

Demo Booking Form: Includes an interactive contact form with a stylish success message simulation.

🛠️ How to Run the Project Locally

Clone or download this repository to your local machine.

Open the beauty-parlour-website folder in Visual Studio Code (VS Code).

Install the Live Server extension in VS Code.

Right-click on the index.html file and select "Open with Live Server".

The website will automatically open in your default web browser at http://127.0.0.1:5500/.
